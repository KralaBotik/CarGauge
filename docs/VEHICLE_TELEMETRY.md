# Телеметрия Hyundai Elantra HD G4FC

Исходные данные предоставил владелец по четырём обследованиям. Адаптер сообщил `ELM327 v2.3`, протокол ISO 15765-4 CAN. Во всех четырёх обследованиях сохранённые и ожидающие коды в полученных ответах отсутствовали. Постоянные коды `0A` дали `NO DATA`, поэтому их статус неизвестен. `011F` вернул 3, 73, 313 и 1170 секунд. Это наблюдения данного экземпляра, без утверждений о других блоках, измеренном расходе или типе запуска.

## Маски

Для страницы с базой N бит 31 обозначает PID N+1, бит 0 — N+32. Младший бит двух первых масок объявляет продолжение. У третьей маски младший бит сброшен.

| Запрос и ответ | Все выставленные биты в виде PID |
| --- | --- |
| `0100 BE3EB813` | `01 03 04 05 06 07 0B 0C 0D 0E 0F 11 13 14 15 1C 1F 20` |
| `0120 80058011` | `21 2E 30 31 3C 40` |
| `0140 BC000000` | `41 43 44 45 46` |

| PID | Значение и преобразование |
| --- | --- |
| `0101`, `0141` | Готовность после очистки, готовность текущего цикла. Маски сохраняются раздельно |
| `0103` | Два байта состояний топливных систем. `02` — штатный замкнутый контур, `04` — открытый контур в условиях движения, которые могут включать и обогащение, и замедление |
| `0104`, `0111`, `0145`, `012E` | Расчётная нагрузка, положение и относительное положение дросселя, заданная продувка адсорбера. `A × 100 / 255` % |
| `0105`, `010F`, `0146` | ОЖ, воздух на впуске, наружный воздух. `A − 40` °C |
| `0106`, `0107` | Кратко- и долгосрочная коррекция смеси. `(A − 128) × 100 / 128` % |
| `010B`, `010C`, `010D` | Абсолютное давление `A` кПа, обороты `AB / 4` об/мин, скорость `A` км/ч |
| `010E` | Опережение зажигания, `A / 2 − 64` градусов |
| `0113`, `0114`, `0115` | Карта кислородных датчиков и обычное напряжение B1S1/B1S2, `A / 200` В. Второй байт сохраняется, он относится к коррекции датчика при её наличии |
| `011C` | Числовой код стандарта OBD |
| `011F` | Время работы двигателя `AB` секунд |
| `0121`, `0131`, `0130` | Пробег с MIL и после очистки DTC в км `AB`, число прогревов после очистки `A` |
| `013C` | Температура катализатора B1S1, `AB / 10 − 40` °C |
| `0143` | Абсолютная нагрузка `AB × 100 / 255` %. Можно отдельно сверить модель воздуха с отчётом ЭБУ |
| `0144` | Заданное отношение смеси `AB / 32768`. В 0.8 это проверка согласованности режима, фактический состав смеси остаётся неизвестным |

`AB = 256A + B`. `0110` (MAF), `015E` (л/ч), `012F` (уровень топлива) и `0142` (напряжение ЭБУ) в исходных масках отсутствуют. Напряжение на приборе может поступить из самостоятельного запроса `0142` при валидном ответе либо из `ATRV`, измерения адаптера. [SAE J1979‑DA, таблицы B2–B54](https://saemobilus.sae.org/standards/j1979da_201110-j1979-da-digital-annex-e-e-diagnostic-test-modes)

## Расписание

Основной цикл публикует ОЖ первым, затем читает обороты. Напряжение обновляется примерно раз в четыре секунды при наличии ответов. При наличии маски в цикле выделяются два приоритетных слота для скорости и MAP, ещё один обслуживает прочие каналы. Целевые интервалы планирования 2 секунды для статуса топлива, 6–10 для заданного отношения, `011F` и температуры впуска, 12–90 для медленных параметров. Это минимальные интервалы между запросами канала. Время адаптера, конкуренция за слот и фон iOS могут замедлить обновление. В фоне низкоприоритетные каналы и диагностика приостанавливаются. Смена пользовательского набора меняет приборы и графики, чтения для истории продолжаются.

Опрос шины последователен. Тайм-аут нарушает сеанс ELM, после переподключения конкретная необязательная команда ждёт до 60 секунд от последнего тайм-аута. Основные измерения могут продолжаться. Для RPM при тайм-ауте предусмотрено повторное чтение после 30-секундной паузы. Период без достоверных оборотов виден в покрытии.

Автоматическая диагностика опрашивает `ATDPN`, затем `03` и `07`, на CAN также `0A`. После первой успешной связи проверка планируется сразу, затем раз в 15 минут активной работы. После быстрого переподключения действует интервал не менее минуты от предыдущего начала. Между циклами выполняется до одного диагностического запроса. Ручное обследование имеет приоритет. Архив хранит исходный отчёт, результат и время. Паспорт протокола и ошибки не дают оснований опрашивать OEM-адреса. [Подтверждённые команды](DIAGNOSTIC_PROTOCOLS.md)
