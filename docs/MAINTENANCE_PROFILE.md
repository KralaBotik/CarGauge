## Обычные и тяжёлые условия

Оба профиля доступны в настройках. Владелец выбирает условия для применения своих интервалов. Частые короткие поездки, холодная погода, соль и продолжительный холостой ход, в том числе автозапуски, полезно проверить по инструкции нужного рынка. Эти факторы присутствуют в руководстве Hyundai для другого рынка HD и помогают сформулировать вопросы к своей сервисной книжке. На их основе интервалы обслуживания российской комплектации не вычисляются. [Руководство Hyundai USA для HD, стр. 7-17–7-18](https://www.hemanual.org/files/downloads/2010%20Hyundai%20Elantra%20%28HD%29%20Owners%20Manual.pdf)

В 0.9 заводские числовые правила для экземпляра выключены. Чтобы сверить применимость, достаточно рынка поставки и фото титула с соответствующей страницей сервисной книжки. VIN для этого сохранять в CarGauge не нужно. После подтверждения нужны вид работы, пределы, условия и единицы. Для пользовательских интервалов форма хранит выбранный профиль и пояснение владельца.

## Каталог и расчёт сроков

- **Замена по применимому интервалу** предназначена для расходников и жидкостей. Срок запускает только соответствующая дата, показание одометра или моточасы последней замены. Осмотр и долив сохраняются в журнале отдельно.
- **Периодический осмотр** учитывает отдельную запись осмотра и назначенный срок повторной проверки. Результат и измерения вводит владелец. Каталог различает оси и позиции для колодок, дисков и шин. Исправное состояние одного колеса не закрывает рекомендацию по другому.
- **По фактическому состоянию** означает запись замеров и решения осмотра. К этой категории относятся, в частности, колодки, диски, сцепление, цепь, подшипники, АКБ и генератор. Пробег после замены не переводится в процент износа. Минимум толщины диска можно записать только вместе с источником, применимым к установленной детали.
- При нескольких пределах используется наиболее срочный, подтверждённый наблюдениями предел. Приблизительные даты и пробег остаются ориентиром и отдельно помечены. История без достаточной опоры не создаёт уведомление о просрочке. Ручной одометр сохраняет приоритет. Оценка по записанным поездкам доступна рядом, с отдельной маркировкой.

Проверки ядра воспроизводят осмотр и долив поверх интервала замены, два режима, неполные данные и приблизительную дату, корректировку одометра, замену после осмотра и полный топливный интервал с учтённой частичной заправкой. Пригодность выбранных интервалов для конкретного экземпляра остаётся задачей владельца и сервисной документации.

Для сопоставления телеметрии с заправкой формы сохраняют дату и время. Историческую запись с неизвестным временем можно пометить приблизительной. Полные интервалы сравниваются только при точных границах и одометре.
