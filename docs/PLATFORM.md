# CarPlay, фон и целевое оборудование

Источники проверены 20 ноября 2026 года.

| Поверхность | Что доступно | Ограничение для CarGauge |
| --- | --- | --- |
| CarPlay Widget | WidgetKit `.systemSmall` с удаляемым фоном доступен в CarPlay с iOS 26. Пользователь добавляет виджет в галерее CarPlay. [Документация Apple](https://developer.apple.com/documentation/widgetkit/adding-standby-and-carplay-support-to-your-widget) | На экране видна дата снимка. Частоту перезагрузки определяет WidgetKit, в том числе после `reloadTimelines`. [Документация Apple](https://developer.apple.com/documentation/widgetkit/keeping-a-widget-up-to-date/) |
| Live Activity | ActivityKit поддерживает CarPlay с iOS 26. Приложение запускает активность на iPhone, а CarPlay может показать её в Dashboard. В проекте используется `.supplementalActivityFamilies([.small])`. [CarPlay Developer Guide](https://developer.apple.com/download/files/CarPlay-Developer-Guide.pdf) | Активность получает обновления от процесса приложения. По истечении `staleDate` интерфейс сообщает об отсутствии свежих данных. [Документация Apple](https://developer.apple.com/documentation/activitykit/displaying-live-data-with-live-activities) |
| Отдельное приложение CarPlay | Apple выдаёт entitlement приложениям поддерживаемых категорий. [Требования Apple](https://developer.apple.com/documentation/carplay/preparing-your-ios-app-for-carplay-development) | Виджет и Live Activity используют системные поверхности без отдельного приложения CarPlay. Возможность вывода собственного полноэкранного приборного экрана в этом проекте не подтверждена. |
| BLE в фоне | `bluetooth-central` позволяет iOS доставлять часть событий, в том числе пробуждать при уведомлении от периферии. [Руководство CoreBluetooth](https://developer.apple.com/library/archive/documentation/NetworkingInternetWeb/Conceptual/CoreBluetooth_concepts/CoreBluetoothBackgroundProcessingForIOSApps/PerformingTasksWhileYourAppIsInTheBackground.html) | ELM327 отвечает на запросы. Между ними таймер приложения может быть приостановлен. Периодический опрос при блокировке экрана, запуск после выгрузки и своевременные фоновые предупреждения требуют проверки. CoreBluetooth State Restoration в прототипе отсутствует. |

Apple документирует iOS 27.2 и Xcode 27.2. Развёртывание на телефоне с конкретной beta-сборкой и показ поверхностей на Linux-магнитоле проверяются отдельно. Workflow использует подтверждённый образ GitHub `macos-26` с Xcode 26.6 и установленный на нём iPhone Simulator. [Примечания iOS 27.2](https://developer.apple.com/documentation/ios-ipados-release-notes/ios-ipados-27_2-release-notes), [состав GitHub runner](https://github.com/actions/runner-images/blob/main/images/macos/macos-26-arm64-Readme.md).

[Vgate](https://www.vgatemall.com/products-detail/i-9/) заявляет поддержку iOS для iCar Pro BLE 4.0. Профиль `18F0/2AF0/2AF1` используется как кандидат на основе [измерения владельца адаптера](https://forum.gps-laptimer.de/viewtopic.php?p=26919#p26919). Фактическое объявление сервиса, свойства характеристик, сон и повторное подключение зависят от экземпляра и прошивки. Формат команд сверяли по [спецификации ELM327](https://www.elmelectronics.com/wp-content/uploads/2016/07/ELM327DS.pdf) и [документации OBD Solutions](https://www.obdsol.com/knowledgebase/obd-software-development/reading-real-time-data/).
