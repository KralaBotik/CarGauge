| BLE в фоне | `bluetooth-central` позволяет iOS доставлять часть событий, в том числе пробуждать при уведомлении от периферии. Apple документирует iOS 27.2 и Xcode 27.2. Развёртывание на телефоне с конкретной beta-сборкой и показ поверхностей на Linux-магнитоле проверяются отдельно. Workflow использует подтверждённый образ GitHub `macos-26` с Xcode 26.6 и установленный на нём iPhone Simulator. [Примечания iOS 27.2](https://developer.apple.com/documentation/ios-ipados-release-notes/ios-ipados-27_2-release-notes), [состав GitHub runner](https://github.com/actions/runner-images/blob/main/images/macos/macos-26-arm64-Readme.md).

Apple указывает App Groups в колонке Apple Developer, которая включает бесплатную регистрацию. Для работы виджета приложение и его расширение должны быть подписаны с одной разрешённой группой. Sideloadly указывает, что его настройка произвольных entitlements требует членства Apple Developer Program и Patreon. Сохранение App Groups для этого неподписанного IPA при бесплатной подписи Sideloadly на Windows не подтверждено. Для первой установки предусмотрен отдельный вариант Basic. [Матрица Apple](https://developer.apple.com/help/account/reference/supported-capabilities-ios/), [настройка App Groups](https://developer.apple.com/help/account/identifiers/enable-app-capabilities/), [журнал Sideloadly](https://sideloadly.io/changelog.html).

[Vgate](https://www.vgatemall.com/products-detail/i-9/) заявляет поддержку iOS для iCar Pro BLE 4.0. Профиль `18F0/2AF0/2AF1` используется как кандидат на основе [измерения владельца адаптера](https://forum.gps-laptimer.de/viewtopic.php?p=26919#p26919). Фактическое объявление сервиса, свойства характеристик, сон и повторное подключение зависят от экземпляра и прошивки. Формат команд сверяли по [спецификации ELM327](https://www.elmelectronics.com/wp-content/uploads/2016/07/ELM327DS.pdf) и [документации OBD Solutions](https://www.obdsol.com/knowledgebase/obd-software-development/reading-real-time-data/).

## Восстановление BLE и автоматизация CarPlay

CarGauge запоминает UUID, проверяет системный список подключённых устройств и кэш CoreBluetooth, затем сканирует по тому же UUID. В активном приложении поиск видит также устройства без объявленного UUID сервиса. Если iOS выдала периферии другой UUID, нужно выбрать адаптер повторно. Характеристики выбираются из известных кандидатов по UUID и проверенным свойствам записи и уведомлений. При неизвестном профиле диагностика показывает найденные UUID сервисов.

State Preservation and Restoration предназначена для управляемых iOS подключений, сканов и подписок с долгоживущим менеджером и стабильным идентификатором. Текущий ELM-менеджер заменяется после тайм-аута и отмены, чтобы запоздавший ответ не попал в соседний сеанс. В этом RC применяется восстановление при открытии приложения. Системное восстановление потребует отдельного владельца BLE и проверки на физическом адаптере. Принудительное закрытие пользователем останавливает фоновое восстановление по CoreBluetooth. [Руководство CoreBluetooth](https://developer.apple.com/library/archive/documentation/NetworkingInternetWeb/Conceptual/CoreBluetooth_concepts/CoreBluetoothBackgroundProcessingForIOSApps/PerformingTasksWhileYourAppIsInTheBackground.html), [Apple QA1962](https://developer.apple.com/library/archive/qa/qa1962/_index.html).

Для личной автоматизации на iPhone откройте **Команды → Автоматизация**, создайте триггер **CarPlay → Подключается**, выберите немедленный запуск и добавьте действие **Открыть приложение → CarGauge**. Триггер CarPlay поддерживает запуск без запроса. Выполнение действия при заблокированном экране и после принудительного закрытия предстоит проверить на iOS 27.2 и целевой магнитоле. [Триггер CarPlay](https://support.apple.com/en-euro/guide/shortcuts/apd8ebfc4e8e/ios), [Автоматический запуск в Командах](https://support.apple.com/guide/shortcuts/add-automations-apdfbdbd7123/ios).
