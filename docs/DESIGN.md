# Приборы CarGauge

Основной экран читается сверху вниз. Выбор источника и кнопка сеанса находятся над прибором температуры. Вторичные показатели идут в одной панели, за ними виден тренд последних пяти минут. Цвет числа и шкалы означает состояние двигателя. Под шкалой оно также подписано текстом и обозначено символом.

| Состояние | Правило при исходных порогах |
| --- | --- |
| Прогрев | Ниже 80 °C и без действующего предупреждения |
| Рабочая температура | От 80 °C, пока не сработало предупреждение |
| Высокая температура | Предупреждение с 105 °C |
| Перегрев | Критическое предупреждение с 115 °C |
| Подключение или потеря данных | Вместо температуры показывается тире и понятный статус |

Пороги задаются в настройках. Между ними сохраняется не менее 4 °C, чтобы предусмотренный гистерезис 3 °C работал без пересечения границ. Эти значения относятся к настройкам CarGauge. Для реальной диагностики сверяйтесь со штатной индикацией автомобиля.

При выключении измерений история последнего сеанса остаётся доступной до начала нового. История хранит в памяти до 30 минут текущего или последнего сеанса. Пропуски от пяти секунд и явные разрывы соединения начинают отдельный участок даже при быстром переподключении. Линия соединяет замеры только внутри участка.

Общие компоненты и палитра находятся в `App/Design`. В тёмной теме основной фон графитовый, светлая использует тёплый нейтральный фон. Медный акцент выделяет действие и выбранный источник. Температурные тона используются только для соответствующих состояний. Системный шрифт поддерживает Dynamic Type, числа рисуются с равной шириной цифр. На размерах доступности показатели перестраиваются вертикально, а декоративная стрелка уступает место числу. Изменение числа учитывает Reduce Motion.

В Xcode есть Previews обеих тем, трёх вторичных вкладок и примера перегрева при крупном тексте. Исходник иконки — `Design/CarGaugeAppIcon.svg`. Растровый ресурс генерируется командой `ffmpeg -i Design/CarGaugeAppIcon.svg -frames:v 1 -pix_fmt rgb24 App/Assets.xcassets/AppIcon.appiconset/CarGauge.png`. Xcode использует его для Basic и Full.
