# Приборы CarGauge

Основной экран читается сверху вниз. Краткий статус подключения находится над прибором температуры. Вторичные показатели идут в одной панели, за ними виден тренд последних пяти минут. Число сохраняет высокий контраст. Шкала подсвечивает одну из четырёх стадий двигателя, рядом со шкалой текущее состояние подписано текстом и обозначено символом.

| Состояние | Правило при исходных порогах |
| --- | --- |
| Прогрев | Ниже 80 °C и без действующего предупреждения |
| Рабочая температура | От 80 °C, пока не сработало предупреждение |
| Высокая температура | Предупреждение с 105 °C |
| Перегрев | Критическое предупреждение с 115 °C |
| Подключение или потеря данных | Вместо температуры показывается тире и понятный статус |

Пороги задаются в настройках. Между ними сохраняется не менее 4 °C, чтобы предусмотренный гистерезис 3 °C работал без пересечения границ. Эти значения относятся к настройкам CarGauge. Для реальной диагностики сверяйтесь со штатной индикацией автомобиля.

При выключении измерений история последнего сеанса остаётся доступной до начала нового. История хранит в памяти до 30 минут текущего или последнего сеанса. Пропуски от пяти секунд и явные разрывы соединения начинают отдельный участок даже при быстром переподключении. Линия соединяет замеры только внутри участка.

Общие компоненты и палитра находятся в `App/Design`. Тёмная тема использует графит с синим подтоном, светлая — холодную нейтральную палитру. Тёплый акцент выделяет основное действие. Температурные тона используются только для соответствующих состояний. Системный шрифт поддерживает Dynamic Type, числа рисуются с равной шириной цифр. На размерах доступности показатели перестраиваются вертикально, а состояние остаётся доступно текстом без шкалы. Цифры меняются сразу, чтобы оставаться чёткими между замерами.

В Xcode есть Previews первого открытия, поездки и перегрева при крупном тексте. Иконку с разомкнутой литерой C и стрелкой приборной шкалы используют Basic и Full. Ресурс хранится в `App/Assets.xcassets/AppIcon.appiconset/CarGauge.png` в формате RGB 1024 × 1024.

## CarGauge 0.4.0

Первое открытие ведёт к подключению адаптера. Экран поиска отдельно показывает вероятные OBD-II устройства и другие находки. Поиск безымянных устройств включается явным действием. После выбора экран показывает проверку, а отмена прекращает её. Сохранение происходит после свежего значения температуры.

Четыре вкладки заменены системным стеком с двумя действиями в верхней строке. **Поездка** показывает текущую историю. **Настройки** ведут к управлению адаптером, порогам, уведомлениям и диагностике. Главный экран показывает график после первого замера. Ось времени показывает длительность поездки, а разрывы BLE разделяют участки.

Тестовые кадры имеют подпись «Тестовые данные», где они показывают замеры. В Release читатель виджета также отбрасывает старые снимки с демонстрационным источником. XCTest сохраняет состояния первого открытия, расширенного поиска, подключения, обе темы поездки, историю, настройки, диагностику, перегрев, обрыв, стоянку и Dynamic Type.

## CarGauge 0.5.0

На главном экране крупная температура, подписанная стадия двигателя и отдельные ячейки оборотов и напряжения. Поездка и настройки открываются из верхней строки. График показывает последние пять минут в масштабе времени поездки. При первом запуске видны инструкция и кнопка поиска. Пустые приборы появляются только после поездки и явно обозначают потерю данных.

Список Bluetooth сохраняет имя из рекламы BLE для текущего поиска. При его отсутствии используется доступное имя устройства в CoreBluetooth. Дубли и безымянные устройства различаются коротким суффиксом локального идентификатора iOS. Если суффиксы совпали, список показывает полный идентификатор. Вероятность принадлежности к OBD-II по имени помогает найти нужную строку. Проверка адаптера по-прежнему требует успешного замера ОЖ.
