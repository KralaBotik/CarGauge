# CarPlay и экран блокировки в CarGauge 0.6.0

Документация Apple проверена 22 ноября 2026. Для обычной установки на iPhone выберите [Full](SIDELOADLY.md). В Full есть Live Activity и виджеты. Для показа в машине требуется CarPlay с iOS 26 или новее. Первой проверяйте Live Activity, поскольку она получает данные прямо из ActivityKit.

## Свежесть и блокировка

- Live Activity запускается после достоверного замера, когда CarGauge открыт и пользователь разрешил автоматический запуск. Она получает текущее состояние через ActivityKit. Доступ к App Group для этого не требуется. При разрыве CarGauge явно помечает активность устаревшей. При остановке передачи ActivityKit получает `staleDate` через 20 секунд после замера. Интерфейс скрывает температуру при признаке устаревания и показывает время замера во время работы. [Жизненный цикл ActivityKit](https://developer.apple.com/documentation/activitykit/displaying-live-data-with-live-activities).
- Снимок виджета подписан временем исходного замера. Запись в timeline после 60 секунд скрывает старое число. WidgetKit выбирает фактический момент замены UI и частоту загрузки. Поэтому показанный таймстамп нужен даже у снимка, который ещё виден. Виджет предназначен для просмотра последнего снимка. [Расписание WidgetKit](https://developer.apple.com/documentation/widgetkit/keeping-a-widget-up-to-date), [переход между записями](https://developer.apple.com/documentation/widgetkit/timeline).
- Файл снимка доступен после первого разблокирования iPhone после перезапуска и защищён до него. Доступность файла в дальнейшем зависит от подписанного App Group. Фоновый Bluetooth подчиняется ограничениям iOS. Режим `bluetooth-central` сам по себе не означает непрерывный опрос или перезапуск после принудительного закрытия пользователем. [Защита файла](https://developer.apple.com/documentation/foundation/nsdata/writingoptions/completefileprotectionuntilfirstuserauthentication), [режимы Core Bluetooth](https://developer.apple.com/library/archive/documentation/NetworkingInternetWeb/Conceptual/CoreBluetooth_concepts/CoreBluetoothBackgroundProcessingForIOSApps/PerformingTasksWhileYourAppIsInTheBackground.html), [перезапуск Core Bluetooth](https://developer.apple.com/library/archive/qa/qa1962/_index.html).

## Запуск через «Команды»

1. Откройте CarGauge, выберите адаптер и оставьте автоподключение включённым.
2. На iPhone откройте **Команды → Автоматизация → CarPlay → Подключается**. Выберите **Запускать немедленно**.
3. Добавьте действие CarGauge **Открыть приборы**. Можно использовать системное **Открыть приложение → CarGauge**.
4. Для первого испытания разблокируйте iPhone до подключения CarPlay. Затем повторите с заблокированным телефоном и проверьте, разрешает ли устройство запуск конкретного действия в текущем состоянии. Автоматизация создаётся пользователем на iPhone. [Триггер CarPlay](https://support.apple.com/guide/shortcuts/travel-triggers-apd8ebfc4e8e/ios), [немедленный запуск](https://support.apple.com/guide/shortcuts/add-automations-apdfbdbd7123/ios).

## App Groups после подписи

Исходный Full сохраняет Bundle ID приложения и расширения и объявляет одну группу для обеих целей. Для обмена iOS проверяет подписанные entitlements и профили. Установленный пользователем Full 0.3.0 через Sideloadly запускал Live Activity и расширение, а обмен снимками отсутствовал. Эта проверка установила симптом. Точная причина остаётся неопределённой, пока нет результата анализа того же переподписанного файла или проверки контейнера на устройстве. [Подпись App Groups](https://developer.apple.com/documentation/xcode/configuring-app-groups), [проверка entitlements](https://developer.apple.com/library/archive/technotes/tn2415/).

Apple указывает App Groups в колонке Apple Developer, доступной для бесплатной регистрации. Это допускает попытку development-подписи на Mac с Personal Team. В Xcode нужно выбрать одну команду для обеих целей, назначить одну группу, получить два профиля с этой группой и установить на подключённый iPhone. Если Xcode не выдаёт оба профиля для конкретной учётной записи, этот путь остаётся заблокированным. У Personal Team короткий срок действия профилей. [Матрица возможностей Apple](https://developer.apple.com/help/account/reference/supported-capabilities-ios/), [Personal Team](https://developer.apple.com/help/account/basics/about-your-developer-account).

Документация Sideloadly предусматривает задание произвольных entitlements в режиме Apple Developer Program с Patreon. Подтверждённого бесплатного способа сохранить одну разрешённую App Group для обеих целей через Sideloadly на Windows в этой среде нет. Можно начать с обычного Full и Live Activity. При наличии файла, подписанного Sideloadly, используйте `python scripts/inspect_app_groups.py CarGauge-Full-signed.ipa` локально. Скрипт сверяет имена групп из обоих Info.plist с XML entitlements и профилями, если они читаются. Разрешения на реальном устройстве подтверждает фактический показ нового снимка. На macOS дополнительно доступны `codesign --display --entitlements :-` для приложения и расширения и `security cms -D -i` для каждого профиля. [Журнал Sideloadly](https://sideloadly.io/changelog.html), [установка](SIDELOADLY.md).

## Проверка CarPlay

Тестирование WidgetKit и Live Activity в отдельном CarPlay Simulator требует Mac и подключённый по USB iPhone. Начиная с Xcode 27, симулятор доступен в Device Hub. Для Xcode 26 Apple распространяет его в Additional Tools for Xcode. Обычный симулятор iPhone с внешним дисплеем документирован Apple для отдельного CarPlay-приложения с entitlement. Его сборка и скриншоты телефона проверяют iPhone-интерфейс и расширение. GitHub-hosted macOS runner не имеет подключённого iPhone для проверки системных поверхностей CarPlay. [Работа с CarPlay Simulator](https://developer.apple.com/documentation/carplay/testing-your-app-in-carplay-simulator), [внешний дисплей iOS Simulator](https://developer.apple.com/documentation/carplay/using-the-carplay-simulator).

1. На неподвижном автомобиле или тестовой магнитоле запустите Full, дождитесь первого замера и появления активности на iPhone. Откройте карту и переключитесь в CarPlay Dashboard. Проверьте температуру, время и читаемость малого представления.
2. Добавьте системный виджет через **Настройки → Основные → CarPlay → ваша машина → Виджеты**, если в этом Full доступен контейнер. Проверьте смену снимка, режимы интерфейса и понятность статуса без данных.
3. Заблокируйте iPhone и дождитесь изменения температуры. Отключите Vgate. Отметьте время, когда Activity перестала показывать число, и задержку скрытия виджетного снимка. Верните питание и проверьте восстановление.
4. Проверьте автоматизацию с разблокированным экраном, затем с заблокированным. Отдельно отметьте результат после принудительного закрытия CarGauge. Запишите версии iOS и прошивки головного устройства.
