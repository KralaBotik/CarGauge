# CarGauge

CarGauge — локальный мониторинг и диагностика Hyundai Elantra HD G4FC с Vgate iCar Pro BLE 4.0. Приборы показывают температуру охлаждающей жидкости, обороты и напряжение. Диагностическая сборка 0.7.0 читает возможности стандартного OBD-II и экспортирует обследование автомобиля.

1. Вставьте адаптер в диагностический разъём и включите зажигание.
2. Откройте CarGauge, нажмите **Найти адаптер**, разрешите Bluetooth и выберите своё устройство. CarGauge сохраняет его после первого ответа с температурой.
3. Открывайте приложение перед поездкой. При включённом автоподключении достаточно сохранённого адаптера. **Поездка** открывает историю замеров, **Настройки** позволяют сменить или забыть адаптер и открыть диагностику.

**Full** — рекомендуемый вариант для iPhone. Он включает Live Activity и WidgetKit. **Basic** предназначен для случаев, когда подпись Full с расширением не проходит. [Установка и обновление с Windows](docs/SIDELOADLY.md), [состояние App Groups и CarPlay](docs/PLATFORM.md).

## Обследование автомобиля

Остановитесь на стоянке, подключите адаптер и откройте **Настройки → Диагностика → Обследование автомобиля**. Доступны карта стандартных PID, readiness, ошибки двигателя и Freeze Frame, когда ответчики их предоставляют. Отчёт можно сохранить как JSON, CSV и TXT. ## Разработка

SwiftUI и CoreBluetooth используются в приложении, Swift Package с ядром проверяется на Linux. Тестовый транспорт доступен в Debug и в CLI разработки. iOS Release получает показания только по BLE.

```bash
swift test
swift run cargauge-simulator reconnect
python3 scripts/validate_project.py
```

На macOS CI запускает XCTest на iPhone 11, проверяет запуск Release с тестовыми аргументами и обновление Full 0.6.0 → 0.7.0 на том же симуляторе. CI сохраняет именованные скриншоты, результаты XCTest, Release IPA и SHA-256. Для устройства нужен iOS 18.0 или новее. Проверка физического Vgate и вывода CarPlay остаётся отдельной приёмкой.
