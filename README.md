# CarGauge

CarGauge — локальный мониторинг и диагностика Hyundai Elantra HD G4FC с Vgate iCar Pro BLE 4.0. Приборы показывают температуру охлаждающей жидкости, обороты и напряжение. CarGauge 0.9.0 добавляет историю диагностических проблем, индивидуальные наблюдения и журнал технического обслуживания к поездкам и экспериментальному расчёту топлива.

1. Вставьте адаптер в диагностический разъём и включите зажигание.
2. Откройте CarGauge, нажмите **Найти адаптер**, разрешите Bluetooth и выберите своё устройство. CarGauge сохраняет его после первого ответа с температурой.
3. Открывайте приложение перед поездкой. При включённом автоподключении достаточно сохранённого адаптера. **Поездка** открывает историю замеров, **Настройки** позволяют сменить или забыть адаптер и открыть диагностику.

Версия 0.9.0 выпускается одним `CarGauge.ipa` с Live Activity и WidgetKit. [Установка и обновление с Windows](docs/SIDELOADLY.md) · [App Groups и CarPlay](docs/PLATFORM.md)

**Поездка** показывает сохранённые измерения, объём и покрытие оценки топлива, пробег и синхронизированные графики. Место базы и калибровка доступны в том же разделе. **Настройки → Показания автомобиля** меняют набор дополнительных параметров на приборах. [Расход и автозапуск](docs/FUEL_ESTIMATION.md) · [Проверка расхода](docs/FUEL_CHECK.md) · [Расшифровка масок](docs/VEHICLE_TELEMETRY.md)

## Мониторинг и обслуживание

В **Диагностике** доступны правила, история DTC, данные срабатываний и повторное чтение. **ТО** содержит интервалы владельца, журнал работ, пробег, осмотры, заправки и расходы. В обоих разделах можно выгрузить локальный отчёт. Интервалы для неизвестной комплектации и рынка не подставляются автоматически. [Правила](docs/DIAGNOSTIC_RULES.md) · [Профиль обслуживания](docs/MAINTENANCE_PROFILE.md) · [Экспорт и резервирование](docs/DATA_EXPORT.md)

## Обследование автомобиля

Остановитесь на стоянке, подключите адаптер и откройте **Настройки → Диагностика → Обследование автомобиля**. Доступны карта стандартных PID, readiness, ошибки двигателя и Freeze Frame, когда ответчики их предоставляют. Отчёт можно сохранить как JSON, CSV и TXT. ## Разработка

SwiftUI и CoreBluetooth используются в приложении, Swift Package с ядром проверяется на Linux. Для сборки пакета на Linux нужны заголовки SQLite (`libsqlite3-dev`). Тестовый транспорт доступен в Debug и в CLI разработки. iOS Release получает показания только по BLE.

```bash
swift test
swift run cargauge-simulator reconnect
python3 scripts/validate_project.py
```

На macOS CI запускает XCTest на iPhone 11, проверяет запуск Release с тестовыми аргументами и обновление 0.8.0 → 0.9.0 на том же симуляторе. CI сохраняет именованные скриншоты, результаты XCTest, `CarGauge.ipa` и SHA-256. Для устройства нужен iOS 18.0 или новее. Совместимость первичного обследования подтверждена владельцем по четырём отчётам. Точность расхода, длительный BLE, уведомления и вывод CarPlay остаются отдельной приёмкой на автомобиле.
